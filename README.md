#FastAPI Lab: Book Managemen API

This project implements a FastAPI server and a Python client to manage
a collection of books using RESTful APIs and JSON serialization.

## Setup
1. Create a virtual environment: "python -m venv venv"
2. Activate it: `source venv/bin/activate` (Windows: `venv/Scripts/activate`)
3. Install dependencies: `pip install -r requirements.txt`

## Running the Server
```bash
cd server
python main.py
